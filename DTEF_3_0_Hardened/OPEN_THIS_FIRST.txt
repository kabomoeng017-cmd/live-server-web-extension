DTEF 3.0 — MILESTONE 4.2 RUNTIME READINESS PACKAGE

START HERE
1. Extract the ZIP archive.
2. Open dtef-3.0.code-workspace in Visual Studio Code.
3. Read README.md, docs/GITHUB_REPOSITORY_SETUP.md and docs/MILESTONE_4_TEST_PLAN.md.

WHAT THIS MILESTONE ADDS
- JUnit/Testcontainers integration coverage for PostgreSQL, Redis and RabbitMQ.
- Playwright browser tests for the student sign-in, identity, document-upload and application-submission journey.
- CI jobs for frontend/backend production builds, JUnit, Playwright, container builds, npm audit, OWASP Maven dependency scanning and simulator contracts.
- OWASP ZAP passive baseline workflow and a manual, allow-listed active scan workflow for authorized staging only.
- Staged k6 load profile with safe target/authorization gates, 100-VU default, progressive stages and JSON summaries.
- Synthetic government-provider simulator for Omang, institution registry, social welfare, FNBB and notifications, with stricter validation and idempotency conflict tests.
- CI now verifies JUnit report counts and fails if PostgreSQL/Redis/RabbitMQ Testcontainers tests are skipped.
- Manual frontend dependency-refresh workflow that regenerates the npm lockfile and opens a PR only after audit, typecheck, unit tests and production build pass.
- Manual, allow-listed load-test workflow for approved HTTPS staging environments; target host must match a protected environment variable and test-JWT use requires explicit trust confirmation.
- Backend container image build compiles test sources without running Testcontainers inside Docker build; the dedicated CI job runs the real integration suite.
- CI evidence verifier now has regression tests for missing, skipped, malformed and failed JUnit reports.
